# 软萌 2048 · 卡通关卡版

一个无需构建步骤的纯 HTML/CSS/JavaScript 2048 小游戏，支持键盘方向键、WASD 和移动端滑动。

## 在线部署（GitHub Pages）

1. 在 GitHub 创建公开仓库 `cute-2048-game`。
2. 将 `index.html` 和 `README.md` 上传到仓库 `main` 分支根目录。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 下选择 **Deploy from a branch**，选择 `main` 和 `/(root)`，点击 **Save**。
4. 等待 Pages 发布，访问 `https://<用户名>.github.io/cute-2048-game/`。

## 本地运行

直接在浏览器中打开 `index.html` 即可。

## Kiro 项目目录

项目包含 `.kiro/steering/`（产品与技术约定）、`.kiro/specs/cute-2048-game/`（需求、设计、任务）以及 `.kiro/hooks/`（预留自动化钩子目录）。这些文件不会影响 GitHub Pages 的静态部署。
